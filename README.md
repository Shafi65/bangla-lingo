# BanglaLingo 🇧🇩

A Duolingo-style app for English speakers learning Bengali (বাংলা).

- **Plan:** [docs/PLAN.md](docs/PLAN.md)
- **Roadmap:** [docs/ROADMAP.md](docs/ROADMAP.md)
- **How the daily build works:** [docs/DAILY.md](docs/DAILY.md)
- **Content format:** [docs/CONTENT_SCHEMA.md](docs/CONTENT_SCHEMA.md)

## Run locally
```bash
npm run validate        # check all lesson content
cd web && npm install && npm run dev   # http://localhost:3000
```

Built day by day with Claude acting as orchestrator. See [docs/LOG.md](docs/LOG.md).
